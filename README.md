# Audio Accuracy Upgrade

Replace `app.py` and `config.json` in `C:\TranslatorV2`, then run `START.bat`.

Recommended settings:
- Audio device: CABLE Output
- Model: medium for accuracy
- Listener volume boost: 2.5x
- Auto-gain target: 0.08
- Noise gate: 0.0035
- Exact spoken language instead of Auto-detect

This upgrade amplifies and cleans the captured audio internally only. It does not increase the volume in your headphones.
